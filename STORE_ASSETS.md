# Store assets

The Fastlane metadata directory contains reusable English and German store text,
five English phone screenshots, and a 512 px app icon.

The screenshots use synthetic budget data. They were captured from Vectorint and
contain no personal or financial information. The store icon is derived from the
unchanged Vectorint Raven source artwork documented in the README and licensed
under CC BY 4.0.

These assets are source material for future store listings. Their presence does
not mean that a release or store submission has taken place.
